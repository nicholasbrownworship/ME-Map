# Map Attribution (Required)

This project is designed to use an external SVG map of Middle-earth that is licensed separately.

## Recommended map asset

**“Map of Middle-Earth.svg”** (author: **k1tesurfen**) is available on Wikimedia Commons under **CC BY-SA 4.0**.  
It lists its source as the **mapome** repository.

When you include that SVG in `assets/middle-earth.svg`, you must provide attribution and keep the share-alike requirement if you distribute modified versions.

- License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
- Author credit: k1tesurfen
- Source references: Wikimedia Commons file page + mapome repository

(If you use a different SVG, replace this with that asset's correct license + attribution.)
